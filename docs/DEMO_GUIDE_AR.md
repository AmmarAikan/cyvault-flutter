# سيناريو العرض الجامعي المختصر

مدة مقترحة: 7–9 دقائق.

1. **المشكلة (45 ثانية):** مخاطر إعادة استخدام كلمات المرور ونسخها غير الآمن.
2. **المعمارية (60 ثانية):** اعرض مخطط `ARCHITECTURE.md` ووضح Riverpod وDrift
   وgo_router وفصل الواجهة عن التشفير.
3. **إنشاء الخزنة (60 ثانية):** أنشئ عبارة تجريبية، ثم جرّب كلمة خاطئة لإثبات
   أن فتح الجلسة يفشل قبل الوصول للبيانات.
4. **CRUD والتشفير (90 ثانية):** أضف عنصرًا اصطناعيًا، ابحث عنه، عدله وأظهر أن
   SQLite لا يحتوي العنوان أو الكلمة بنص واضح.
5. **المولّد والصحة (60 ثانية):** ولّد كلمة، اعرض قوة/إعادة استخدام/قدم الكلمة.
6. **HIBP (60 ثانية):** وضح إرسال البادئة ذات 5 محارف فقط والموافقة الاختيارية.
7. **النسخة الاحتياطية (60 ثانية):** صدّر بعبارة مستقلة وبيّن رفض العبارة الخطأ.
8. **الجودة (45 ثانية):** اعرض CI، الاختبارات والتغطية والبناء، ثم القيود
   الواقعية: لا مزامنة سحابية ولا تدقيق مستقل، وIPA يحتاج macOS.

استخدم بيانات تجريبية فقط ولا تعرض كلمة رئيسية أو ملف نسخة حقيقي في التسجيل.
