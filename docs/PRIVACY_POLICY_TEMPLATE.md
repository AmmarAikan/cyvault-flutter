# Privacy policy template — review and host before release

**Template only; obtain appropriate legal review and replace every bracketed
field before publishing.**

CyVault stores vault data locally in encrypted form. Version 1 has no CyVault
account, analytics or cloud synchronization. If the user explicitly enables
online breach checks, the app sends a five-character SHA-1 prefix over HTTPS to
the Have I Been Pwned Pwned Passwords range service; it does not send the
plaintext password, full hash, username or vault metadata. The provider's policy
applies to that request.

Encrypted backups are created only at the user's request and shared to a
destination the user selects. Biometric processing is performed by the device OS
and CyVault receives only success/failure. Local redacted security events contain
event category/time, not secrets.

services and links, children's policy, legal bases/rights where applicable,
effective date and change notice. Host the final URL publicly and use the exact
same disclosures in Google Play Data safety.
