# دليل استخدام ساي فولت

1. عند التشغيل الأول اقرأ التنبيه وأنشئ عبارة رئيسية قوية لا تقل عن 12 محرفًا.
   لا توجد آلية لاستعادتها إذا نُسيت.
2. أضف عنصرًا يتضمن العنوان واسم المستخدم وكلمة المرور والرابط والملاحظات
   والوسوم. تُشفّر الحقول الحساسة معًا، ويعمل البحث بعد فكها داخل الذاكرة فقط.
3. استخدم المولّد لإنشاء كلمة عشوائية آمنة. تُمسح الحافظة بعد المهلة فقط إذا
   بقيت القيمة نفسها، حتى لا يمسح التطبيق نصًا نسخه المستخدم لاحقًا.
4. فحص التسريب عبر الإنترنت متوقف افتراضيًا. بعد الموافقة يُرسل أول خمسة محارف
   فقط من SHA-1 إلى خدمة Pwned Passwords ولا تُرسل الكلمة أو بيانات الحساب.
5. صدّر نسخة `.cyvault` بعبارة مستقلة وقوية واحفظها بعيدًا عن الجهاز. يتحقق
   الاستيراد من سلامة الملف قبل تطبيق خيار التخطي أو الاستبدال أو إنشاء نسخ.
6. استخدم زر القفل. الانتقال للخلفية وعدم النشاط يقفلان الجلسة أيضًا. القياسات
   الحيوية خطوة تأكيد ثانية بعد الكلمة الرئيسية وليست بديلًا عنها.
7. تقرير PDF يعرض أرقامًا إجمالية فقط ولا يتضمن أسرارًا.

فقدان الكلمة الرئيسية وكل عبارات النسخ الاحتياطية يعني استحالة استعادة البيانات
حسب التصميم.
